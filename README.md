# shelfware

> shelfware finds the shelfware in your skill drawers.

A local catalog, audit & cleanup tool for AI agent skills
(`~/.claude/skills`, `~/.cursor/skills`, `~/.codex/skills`, …).
Browse, search, edit, audit for suspicious patterns, and quarantine
what you no longer use — before it eats your context window.

```bash
npx shelfware
```

**Status:** under active development, first release soon.

Nuxt 4 · runs strictly on `127.0.0.1` · nothing leaves your machine

Inspired by [skill-cabinet](https://github.com/subsy/skill-cabinet) (MIT) —
rebuilt from scratch with editing, hardened local security, and a Nuxt UI interface.
